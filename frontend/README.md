# 🎨 SPA de Usuários (Frontend)

Aplicação **Single-Page** em React para **interagir** com a API de usuários, oferecendo UI para CRUD completo.

### 📌 Para que serve
- Permitir ao usuário final visualizar e gerenciar cadastros.
- Demonstrar integração frontend ↔ backend via chamadas HTTP.
- Apresentar interface responsiva e amigável.

---

### 🚀 Principais Tecnologias
| Tecnologia       | Uso                                                         |
| ---------------- | ----------------------------------------------------------- |
| Vite             | Bundler rápido para desenvolvimento e build                |
| React + TypeScript | Biblioteca UI com tipagem segura                           |
| Axios            | Cliente HTTP para consumir API                             |
| React Router DOM | Navegação entre telas sem recarregar a página              |
| Bootstrap 5      | Sistema de grid e componentes pré-estilizados              |
| Google Fonts     | Import de fonte **Poppins** para tipografia moderna        |
